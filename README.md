# Museum Planning LLC — Website (`website-2.0`)

Public marketing site for **[museumplanning.com](https://museumplanning.com/)**, hosted on **GitHub Pages** from this repository (`main` branch).

## What this repo is

- Static **HTML** site (no build step required for publish).
- Primary goals: **credibility**, **lead generation** (conversation → feasibility → broader engagements), and **SEO** for museum planning–related intent.
- **`STYLE-GUIDE.md`** is the source of truth for layout, nav, typography, and footer patterns.

## Documentation

| File | Purpose |
|------|---------|
| [STYLE-GUIDE.md](./STYLE-GUIDE.md) | Design system, global nav, footer, pre-publish checklist |
| [SITE-STRATEGY.md](./SITE-STRATEGY.md) | Audience, funnel, keyword clusters, key URLs (internal reference) |

## Local preview

Serve the repo root with any static server, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

## Deploy

Changes pushed to `main` update **GitHub Pages** for the configured custom domain (**museumplanning.com**).

## Related repos

This repository is **Museum Planning LLC** web presence — not personal/artwork sites. Commercial positioning and production copy for the firm belong here.
