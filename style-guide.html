Internal Standard

Website Style Guide

The source of truth for visual and structural consistency in `website-2.0`.

1) Design System

Do Not Drift

Use this design system on all core pages unless a deliberate rebrand is approved and rolled out globally.

--deep: #111C27
--gold: #C9A84C
--gold-lt: #E8D099
--cream: #F8F4EC
--ink: #1A1A1A
--mid: #5A5A5A
--rule: #D4C8B0
  • Serif display/headlines: Playfair Display
  • Utility labels/nav/meta: DM Mono
  • Body copy: Lato
  • Tone: premium, practical, direct — use we on commercial pages, not first-person I
2) Global Navigation

Standard Order

  1. Services
  2. For Cities
  3. For Universities
  4. Projects
  5. Museum School
  6. Science Centers
  7. About
  8. Contact
  9. Search icon
  10. Start a Conversation (CTA)
  • Fixed 60px dark nav with gold CTA.
  • Use assets/nav-mobile.css and assets/nav-mobile.js.
  • Keep search IDs consistent: searchToggle, searchOverlay, searchClose, searchResults.
3) Paths and URLs

Link Conventions

  • Use consistent root/site-relative links within each page.
  • For nested pages (projects/*, museum-school/*, documents/*), adjust path depth correctly.
  • If maintaining mirrored files in multiple locations, update all copies in one change set.
  • Canonical URLs should match final GitHub Pages location.
4) Page Structure

Required Composition

  1. Fixed global nav
  2. Hero with dark field and serif headline
  3. Readable body sections/cards
  4. CTA block with gold primary action
  5. Standard footer
  6. Search overlay + scripts
5) Page Tiers

SEO / Information Architecture

One primary URL per keyword cluster. Cross-link between tiers; do not duplicate intent.

  • Tier 1 (sitemap 0.85): museum-feasibility-study.html, museum-strategic-planning.html, museum-master-planning.html, museum-planning-services.html
  • Tier 2 (sitemap 0.45): for-cities.html, for-cities-science-center.html, local-history-museum.html, immersive-museum-planning.html, for-universities.html
  • Tier 3: museum-school/*.html — link up to commercial pages

Template: Tier 1 → museum-feasibility-study.html. Tier 2 → local-history-museum.html or immersive-museum-planning.html.

6) SEO Standard

Head, Schema, and Redirects

  • Unique title + ~155-char meta description; canonical with .html
  • Open Graph + Twitter Card; JSON-LD: WebPage, FAQPage (must match visible FAQ), BreadcrumbList
  • Add URL to sitemap.xml; legacy paths in redirects/legacy-redirects.json
  • Run python3 tools/gen_legacy_redirect_stubs.py and gen_cloudflare_bulk_redirects.py after redirect changes
  • No meta keywords; no keyword-stuffed headings
7) Social Media Standard

How Social Links Are Managed

  • Official platforms (if active): LinkedIn, Instagram, X.
  • Default placement: footer on all primary pages.
  • Optional additional placement: contact page only.
  • Order: LinkedIn, Instagram, X.
  • Text labels only (not icon-only).
  • Open external links in a new tab with target="_blank" and rel="noopener noreferrer".
  • No placeholders: if a platform is not active, omit it.
  • Use identical URLs and order across every page where social links appear.
8) Consistency Rules

Operational Standards

  • Desktop side padding baseline: 56px; mobile: 24px.
  • Keep terms exact: Museum School, Start a Conversation, Museum Planning LLC.
  • Avoid one-off visual systems on individual pages.
  • Pre-publish checklist: nav, mobile nav, search, tokens, links, footer, social standard, SEO head, sitemap, voice (we not I), no theme drift.
  • Full spec: STYLE-GUIDE.md in repo root.
  • If intentionally changing the standard, document rationale and update the style guide.
