# Landscape — who else does this

Based on three web searches on 2026-11-25. Not exhaustive. Pricing, licensing, and macOS support were **not** checked.

## Managed monitoring and support for installed exhibits

| Who | What | Link |
|-----|------|------|
| X Studios (Xapp) | Cloud dashboard, device telemetry, remote restart, fleet updates. Raspberry Pi, Linux, Windows, macOS. | https://xapp.xstudios.com/ |
| Art Plus Code | Takes over installations they did not build. Remote monitoring, updates, yearly site visit, from CAD $1,500/year. Condition report CAD $3,000. Kiosks run offline. | https://www.artpluscode.com/en/services/interactive-kiosks-for-museums/ |
| PivotXP | Kiosk lockdown, self-recovery, remote monitoring with screen thumbnail, content manager. | https://www.pivotxp.com/permanent-installations |
| KIOSK | Managed monitoring, hardware and OS support, field service. | https://kiosk.com/wp-content/uploads/2024/09/KIOSK-Support-Services-Brochure-.pdf |
| Aether Immersive | Single-station museum kiosks quoted $15k-$50k, remote support contracts. | https://aetherimmersive.com/solutions/museums/ |

## Collections and media across several museums

| Who | What | Link |
|-----|------|------|
| Exhibitera | Free, open source, built by museums. Touch interactives, signage, device status, scheduling, analytics. Closest to this idea. | https://exhibitera.org/ |
| Carousel + BrightSign | Cloud signage. Ingenium runs 50 screens across three museums. | https://www.carouselsignage.com/case-studies/ingenium |
| MuCoDi | One set of collection records feeds website, QR codes, gallery touchscreens. | https://www.mucodi.co/en |
| Axiell CultureConnect | Collection-driven interactives for kiosks and touch tables. | https://www.axiell.com/solutions/product/cultureconnect/museum-advanced-interactives/ |
| Custom Collections Series | 65" touch table, cloud admin portal, database that ingests collection data. | http://www.mua.nz/wp-content/uploads/2019/07/Custom-Collection-Series-Specifications-amended.pdf |

## Post office exhibits and games

- The Postal Museum, London: Post Bus game and Mail Coach game — https://heritageinteractive.co.uk/the-postal-museum-london
- Smithsonian National Postal Museum: Post-Haste touch-table game — https://postalmuseum.si.edu/post-haste-home
- Seattle Children's Museum and Iowa Children's Museum: hands-on sorting, weighing, stamping rather than a touchscreen game.

## Takeaways

- The managed-support model already exists. Most vendors found serve large institutions or a single regional market.
- No vendor serving small Georgia or Southeast museums turned up, but only three searches were run.
- Exhibitera is free and covers device status and scheduling. Worth evaluating before building the monitoring layer.
- Maintenance can be sold as its own service (Art Plus Code does).
